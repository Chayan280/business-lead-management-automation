# Automated Business Lead Management & Email Notification System

## Overview
A no-code business automation project built using Zapier, Google Forms, Google Sheets, and Gmail to simplify lead collection and email communication.

## Workflow
1. Customers submit their details through Google Forms.
2. Zapier captures each new form response.
3. Lead information is automatically added to Google Sheets.
4. An admin notification email is sent through Gmail.
5. Customers receive an automatic acknowledgement email.

## Tools Used
- Zapier
- Google Forms
- Google Sheets
- Gmail

## Key Features
- Automated lead collection
- Centralized lead tracking
- Automatic admin email notifications
- Customer acknowledgement emails
- Reduced manual data entry
